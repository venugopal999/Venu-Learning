💻 C Programming

Learn C programming from the fundamentals to advanced concepts with examples, programs, explanations and practice.

📖 1. Introduction to C

C is a general-purpose programming language developed by Dennis Ritchie at Bell Labs.

C is widely used for system programming, embedded systems, operating systems and learning programming fundamentals.

💡 Why learn C?

C helps you understand memory, pointers, arrays, functions and the fundamental concepts required for Data Structures and Algorithms.

🏗️ 2. Structure of a C Program

A basic C program contains header files, the main function and program statements. 


#include <stdio.h>

int main()
{
    printf("Hello World");

    return 0;
}

Explanation

  • #include includes a header file.
  • main() is the starting point of execution.
  • printf() displays output.
  • return 0 indicates successful execution.

🔤 3. Variables & Constants

A variable is a named memory location used to store data. 


int age = 20;

float marks = 85.5;

char grade = 'A';
Syntax:

data_type variable_name = value;

📦 4. Data Types

Data types specify what type of data a variable can store.

Common C Data Types

int → Integer numbers
float → Decimal numbers
double → Large decimal values
char → Single character

⌨️ 5. Input & Output

Output


printf("Hello");

Input


int age;

scanf("%d", &age);
💡 Remember:

scanf() is generally used to read input from the user.

➕ 6. Operators

  • Arithmetic Operators
  • Relational Operators
  • Logical Operators
  • Assignment Operators
  • Increment / Decrement
  • Bitwise Operators
  • Conditional Operator
Example:

int a = 10;
int b = 3;

a + b = 13
a - b = 7
a * b = 30
a / b = 3
a % b = 1

🧮 7. Expressions

An expression is a combination of operands and operators that produces a value. 


int result;

result = a + b * 2;
💡 Operator precedence determines which operation is performed first.

🔀 8. If / Else 


if (age >= 18)
{
    printf("Eligible");
}
else
{
    printf("Not Eligible");
}

Conditional statements are used to make decisions in a program.

🔀 9. Switch Statement 


switch(choice)
{
    case 1:
        printf("Addition");
        break;

    case 2:
        printf("Subtraction");
        break;

    default:
        printf("Invalid choice");
}

🔁 10. Loops

Loops are used to execute a block of code repeatedly.

for loop


for(int i = 1; i <= 5; i++)
{
    printf("%d ", i);
}

while loop


int i = 1;

while(i <= 5)
{
    printf("%d ", i);

    i++;
}

do-while loop


int i = 1;

do
{
    printf("%d ", i);

    i++;

} while(i <= 5);

📊 11. Arrays

An array stores multiple values of the same data type in contiguous memory locations. 


int numbers[5];

numbers[0] = 10;
numbers[1] = 20;
numbers[2] = 30;

🔤 12. Strings

A string is a sequence of characters terminated by the null character '\0'. 


char name[20];

scanf("%s", name);

printf("%s", name);

🧩 13. Functions

Functions are reusable blocks of code designed to perform a particular task. 


int add(int a, int b)
{
    return a + b;
}


int main()
{
    int result;

    result = add(10, 20);

    printf("%d", result);

    return 0;
}

👉 14. Pointers

A pointer is a variable that stores the memory address of another variable. 


int x = 10;

int *p = &x;

printf("%d", *p);
💡 Pointers are one of the most important concepts in C and Data Structures.

🏗️ 15. Structures & Unions

Structures allow us to group different types of data under one name. 


struct Student
{
    int rollNo;

    char name[30];

    float marks;
};

📁 16. File Handling

File handling allows programs to store and retrieve data from files. 


FILE *fp;

fp = fopen("data.txt", "w");

fprintf(fp, "Hello");

fclose(fp);
